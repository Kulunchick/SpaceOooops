# No backend: team play is local on one screen, hosted as a static site

The brief asks for up to four collaborating players. With a ~36-hour hackathon deadline we chose local team play on a single screen (Roles, Go/No-Go, Personal Objectives) and a static GitHub Pages deploy with no server. Networked multiplayer, leaderboards and cloud saves are out of scope; history lives in `localStorage` and designs are shared by encoding them in a URL.
