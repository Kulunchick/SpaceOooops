# 09: Models for the star events

**What to build:** Four events get their own low-poly model instead of the generic fly-by or visitor shape: the UFO (F1), the space whale (F2), the dragon (F6) and the rival agency's inspector satellite (33). An event names its model in the catalog file; an event without one keeps the generic shape.

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] An event can name a model for its fly-by or visitor effect in the catalog file; catalog tests reject an unknown model name
- [ ] The four models are original low-poly geometry in the game's palette, with no marks of any real agency or country
- [ ] Each model stays within the face budget of the Low Graphics setting
- [ ] The Scene Spec carries the model name for these events and none for the others
- [ ] Any new third-party asset is listed in the credits data
